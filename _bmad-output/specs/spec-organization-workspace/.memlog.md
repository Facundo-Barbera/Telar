- (capability) CAP-2 Brain dump to receipt — one multi-project dump parsed, split, routed; receipt count matches input and names what is unplaceable.
- (capability) CAP-3 Desk rail — agent-filed items land on a right rail, edited in place by talking, dismiss drains to the queue and never deletes.
- (capability) CAP-4 Queue with dynamic lanes — dense grouped list; lanes are user-owned data with ordered stacks; master may propose a split, human accepts.
- (capability) CAP-5 Item spectrum with sub-tasks inside — one-line todo through rich packet; decomposition lives inside the item so the queue count never grows from breakdown.
- (capability) CAP-6 Work packet ripening — raw fragment to fixed brief + acceptance criteria, attachments accrue over days, timeline attributes every event to you/expert/bed with proposals marked.
- (capability) CAP-7 Deadlines as data + self-deadline witness — external vs self deadlines, self ones count slips; the master surfaces slid self-deadlines in the briefing as a reset-or-drop question, never an alarm. (User-confirmed from parked.)
- (capability) CAP-8 Calendar gap detection — external calendar plus mined spoken commitments act as an expectation source; the master surfaces expected-but-uncaptured events in the briefing with capture chips. (User-confirmed from parked.)
- (capability) CAP-9 Ephemeral per-project experts — spawned per call, rehydrated from an on-disk project digest; decompress shorthand a generic agent cannot, and issue a session-or-loom triage verdict.
- (capability) CAP-10 Bed mode — overnight organization pass bounded by prepare-never-commit; outputs are proposals; the morning header reports the run as actions-taken with zero started.
- (capability) CAP-11 Loom and session handoff — a ripened packet or a selected batch hands over premise + context and the loom detaches, leaving the universal one-line detach receipt; the packet stays as origin receipt.
- (capability) CAP-12 Tasks as a Telar-wide substrate — any session reads, creates, and modifies the same items via workspace tools; provenance records which surface did it.
- (capability) CAP-13 External sources as reference — workspace-scoped MCP servers are read for reference only; nothing becomes a task unless the human says so.
