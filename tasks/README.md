# Telar development desk

GitHub Issues is the source of truth for task status, scope, discussion, and acceptance:

https://github.com/Facundo-Barbera/Telar/issues

The user chooses what starts. The orchestrator maintains statuses and supervises Telar agents. A shipped feature stays in Review until accepted. Do not maintain a second local backlog.

Status labels: `status:backlog`, `status:ready`, `status:in-progress`, `status:review`, `status:done`. GitHub Project board creation is pending Projects authorization as of 2026-09-08.

Local files are supporting artifacts only:
- `DECISIONS.md`: workflow and protection of nightly installation/data.
- `HISTORY.md`: historical delivery and retired work, not a live task list.
- `screenshots/`: retained evidence. CHAT-001 screenshot remains local and is not uploaded to GitHub; issue #194 describes it and records its path.
